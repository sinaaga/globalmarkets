# CryptoVerse & Global Markets

Platform untuk memantau pergerakan pasar cryptocurrency dan saham internasional secara real-time.

## Tech Stack

- **Framework**: React 18 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Charts**: Recharts
- **Icons**: Lucide React

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output akan ada di folder `dist/`

## Deploy

Project ini dioptimalkan untuk deploy ke Vercel dengan konfigurasi Vite.
